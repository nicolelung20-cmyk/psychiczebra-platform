# Elevat Agent Factory

The factory is a bounded verification layer for the first-party Elevat repository estate.

## Gates
- install, typecheck, lint, tests, and production build
- nightly, push-to-main, or manual execution
- machine-readable verification artifact
- read-only GitHub permissions

## Boundaries
The factory does not send external outreach, spend money, move funds, claim revenue, or deploy production by itself. Production remains governed by the repository/Vercel deployment path and review.

Upstream/vendor mirrors remain excluded by default.
