# Kit delivery notes (internal)

`workflow-brief-kit.md` is the product sold by the $47 Stripe Payment Link in `lib/payment-links.ts` (`workflowBriefKit`).

## Before the first customer
1. Read the kit once and edit anything that does not sound like you. It is a draft.
2. Export it to a PDF or a Google Doc (Drive folder `Elevated Associates/Contracts` or a `Products` folder) and set sharing to "anyone with the link can view".
3. In the Stripe dashboard, open the payment link, then After payment, choose "Don't show confirmation page" and enter a custom message that includes the link. Stripe's receipt email will not carry the file by itself.
4. Make a test purchase (Stripe test mode or a 100%-off coupon) and confirm the buyer actually receives the link.

## Rules
- Do not add testimonials, customer logos or results. The example in the kit is labelled hypothetical; keep it that way.
- The upsell paragraph points to the Readiness Sprint. Keep it optional and honest.
